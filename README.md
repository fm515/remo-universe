# REMO UNIVERSE — Foundation v0.1.0

واجهة تأسيسية أولية لمنظومة REMO UNIVERSE متعددة الوحدات.

## التشغيل
- `npm install`
- `npm run dev`
- `npm run build`

## الحالة
هذه نسخة تأسيسية للواجهة والتنقل فقط. وحدات AI وTRADE وWALLET وSTORE وLIFE وNETWORK غير مفعّلة بعد، ولا توجد مدفوعات أو تداول أو حفظ أموال حقيقي.
